# 🎓 Campus Discovery Website

A full-stack web application designed for university campuses to centralize events, club activities, announcements, and student participation.

---

## 📌 Features

- **Event Management**: Browse, search, filter, and view detailed information for campus events.
- **Event Registration**: Students can register for upcoming workshops and competitions.
- **Clubs & Communities**: Explore student organizations and clubs.
- **Campus Announcements**: Real-time updates and important college notifications.
- **Admin Dashboard**: Manage events (create, update, delete) and view registration counts.
- **User Authentication**: Student login, registration, and password recovery.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+), Responsive Design
- **Backend**: Java 17, Spring Boot 3, Spring Data JPA, RESTful APIs
- **Database**: MySQL
- **Build Tool**: Maven Wrapper (`mvnw`)
